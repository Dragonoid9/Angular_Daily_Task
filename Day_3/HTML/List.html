Unordered List Example

An unordered list is used when the order of the items doesn't matter. The items are typically marked with bullets.

  • Apple
  • Banana
  • Cherry
  • Orange

Ordered List Example

An ordered list is used when the order of the items matters, and they are typically numbered.

  1. First step
  2. Second step
  3. Third step
  4. Fourth step

Definition List Example

A definition list is used to define terms and their descriptions.

HTML
HyperText Markup Language, the standard language for creating web pages.
CSS
Cascading Style Sheets, used to style HTML elements on the web page.
JavaScript
A programming language used to create interactive effects within web browsers.
